# RelationalRAG-Tables Reproducibility Artifact

This artifact reproduces the experimental evidence for *RelationalRAG-Tables*, a
learned, calibrated, abstention-aware **join verifier** for question answering
over relational tables and knowledge graphs. It requires no LaTeX source to
reproduce the results. The compiled supplement is included as `supplement.pdf`.

The artifact produces machine-readable JSON results, with SHA-256 + size
provenance for every reported number in `artifacts/manifest.json`.

**Scope and boundary.** This folder is the self-contained code artifact: the
synthetic core package, the optional real-data layer, fixtures, stored result
manifests, unit tests, run scripts, a Dockerfile, and the compiled supplement.
Manuscript LaTeX source and the main-paper PDF are intentionally excluded;
`check_artifact.py` enforces that no `.tex`/`.aux`/`.bbl` or stray `.pdf` (other
than `supplement.pdf`) ships here.

**Two layers.**

- **Synthetic core** (`relational_rag_tables/`) — NumPy + scikit-learn only, CPU,
  no network. Deterministic. Regenerates every controlled-study, selective-
  prediction, calibration, and diagnostics result in well under a minute.
  Dependencies: `requirements.txt`.
- **Real-data layer** (`relational_rag_real/`) — optional and environment-heavy
  (Python 3.13, Apple-silicon GPU via MPS + MLX, a sentence encoder, a vector
  index, a local quantized code model, and public benchmark downloads).
  Reproduces the ICD-10/Wikidata, BIRD, and HybridQA numbers. Dependencies:
  `requirements-real.txt`. Seeded but not bit-identical across hardware.

## What Is Included

- The synthetic join-verifier pipeline: ingest, column/edge encoders, relational
  retriever, execution-aware planner, learned/ensemble verifier, uncertainty
  head, and the controlled-study / calibration / diagnostics harnesses.
- The real-data drivers for the ICD-10 + Wikidata table+KG benchmark,
  cross-vocabulary and heterogeneous-drift joins, the fine-tuned cross-encoder,
  BIRD value linking and end-to-end execution accuracy, and HybridQA.
- `fixtures/` (the smoke fixtures; the synthetic corpus is regenerated on demand).
- `artifacts/` — stored result JSONs with `manifest.json` (SHA-256 + byte size).
- Reproduction scripts (`run_smoke.sh`, `run_full.sh`) that touch no LaTeX/PDF.
- A checker (`check_artifact.py`) that verifies completeness and that no
  manuscript source leaked in.
- `supplement.pdf`, the compiled supplementary material.

## What Is Not Included

- No manuscript `.tex`, `.bbl`, or `.aux` files; the only shipped PDF is
  `supplement.pdf`.
- No author names, institutions, or contact details are needed to reproduce.
- Large public datasets and pretrained models are downloaded by the real-data
  layer rather than bundled.

## Hardware And Time

The synthetic core is **CPU-only** and finishes in **well under a minute**:

```bash
python3 -m venv env && env/bin/pip install -r requirements.txt
env/bin/python check_artifact.py        # completeness + hygiene
bash run_smoke.sh                        # tests + reference pipeline + manifest verify
bash run_full.sh                         # regenerate all synthetic results, verify vs manifest
```

Or with Docker (CPU-only core):

```bash
docker build -t relationalrag-artifact .
docker run --rm relationalrag-artifact   # runs check_artifact.py then run_smoke.sh
```

The real-data layer needs a separate environment and an Apple-silicon GPU:

```bash
python3.13 -m venv env && env/bin/pip install -r requirements-real.txt
env/bin/python -m relational_rag_real.run_icd_kg     # and the other run_* drivers
```

## Structure

```
relational_rag_tables/   synthetic core: pipeline, verifier, calibration, diagnostics
relational_rag_real/     optional real-data drivers (ICD-10/Wikidata, BIRD, HybridQA)
tests/                   unit tests (python -m unittest discover -s tests)
fixtures/                smoke fixtures (synthetic corpus regenerated by `synthesize`)
artifacts/               stored result JSONs + manifest.json (sha256 + bytes)
run_smoke.sh             fast, non-destructive plumbing check (< 1 min)
run_full.sh              full synthetic regeneration + manifest verification
check_artifact.py        completeness + no-LaTeX-leak hygiene check
Dockerfile               CPU-only core image
supplement.pdf           compiled supplementary material
REPRODUCE.md             result-to-command map, seeds, environments, provenance
```

See `REPRODUCE.md` for the per-result command map, seeds, tested package
versions, and provenance regeneration.
